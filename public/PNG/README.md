# 遊戲圖片資源

請將以下圖片放入此資料夾：

**支持格式**：PNG、JPG、JPEG、WEBP、GIF（系統會自動嘗試載入）

## 武器圖片
- `Shotgun` - 霰彈槍圖示
- `Rifle` - 步槍圖示
- `Sniper` - 狙擊槍圖示

## 瞄具圖片

### 清晰版瞄具
- `SniperScope` - 狙擊鏡瞄具覆蓋層（全螢幕，圓形瞄準鏡+十字線，**置中對齊**）
- `RifleScope` - 步槍倍鏡瞄具覆蓋層（全螢幕，小型瞄準鏡，**底部對齊**）
- `ShotgunScope` - 霰彈槍倍鏡瞄具覆蓋層（全螢幕，瞄準鏡，**底部對齊**）
- `RifleIronSight` - 步槍機械瞄具覆蓋層（全螢幕，準星，**底部對齊**）
- `ShotgunIronSight` - 霰彈槍機械瞄具覆蓋層（全螢幕，準星，**底部對齊**）

### 模糊版瞄具（焦距切換用）
- `SniperScopeFuz` - 狙擊鏡模糊版（背景清晰時使用）
- `RifleScopeFuz` - 步槍倍鏡模糊版
- `ShotgunScopeFuz` - 霰彈槍倍鏡模糊版
- `RifleIronSightFuz` - 步槍機瞄模糊版
- `ShotgunIronSightFuz` - 霰彈槍機瞄模糊版

**焦距切換功能**：瞄準時點擊螢幕（開火鍵除外）可切換「瞄具清晰/背景模糊」↔「背景清晰/瞄具模糊」

## 道具圖片
- `Radar` - 雷達道具圖示
- `Flashbang` - 閃光彈道具圖示
- `Airstrike` - 空襲道具圖示

## 遊戲截圖
- `Hit.jpeg` - 射擊時自動儲存的截圖（程式自動覆蓋）
- `RealHit.jpeg` - AI 判定命中後複製的截圖（用於申訴）

## 建議圖片規格
- 武器圖示: 120x80px, 透明背景
- 瞄具覆蓋: 1080x1920px (手機螢幕比例), 透明背景
- 道具圖示: 64x64px, 透明背景

## 注意事項
- 檔案名稱必須正確（不含副檔名）
- 系統會自動嘗試以下格式：.png → .jpg → .jpeg → .webp → .gif
- 如果所有格式都找不到，會顯示檔案名稱作為佔位符
